# Codex 작업 브리프

## 큰 작업 시작용

```text
이 작업은 phase로 나눠서 진행해.

목표:
source of truth:
수정 허용 범위:
금지사항:
검증 기준:

시작 전에 위 기준을 먼저 정리하고,
각 phase 끝마다 변경 파일 / 검증 결과 / 남은 리스크 / 다음 작업만 짧게 보고해.
```

## 핵심 축 보존용 (문서 다듬기·요약)

```text
이 문서의 핵심 축은 다음과 같다: <축 1>, <축 2>, <축 3>.
문장을 줄이거나 다듬더라도 이 축은 절대 약화하지 마.
수정 후에는 각 축이 살아 있는지 짧게 점검해.
```

`<축 N>`에는 어떤 수정에도 살아남아야 하는 문서의 정체성(핵심 경험, 관점, 강점)을 2~5개 적는다. 아직 정하지 못했다면 `/brief-tuner` 인터뷰로 도출할 수 있다.

## 긴 작업 분할용

```text
이번 세션에서는 전체를 끝내려 하지 말고, 다음 phase만 완료해.

이번 phase:
완료 조건:
건드리면 안 되는 범위:

끝나면 변경 파일, 검증 결과, 남은 리스크만 보고해.
```
