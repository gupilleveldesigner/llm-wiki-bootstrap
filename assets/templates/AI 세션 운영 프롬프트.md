# AI 세션 운영 프롬프트

## 긴 작업을 끝까지 진행

```text
goal 기능을 사용해 줘.

목표:
산출물:
완료 조건:
검증 방법:
수정 허용 범위:
금지사항:
```

## 구현 전 기획 점검

```text
plan 기능을 사용해서 먼저 기획과 작업 범위를 점검해 줘.

현재 문제:
의도한 경험 또는 결과:
source of truth:
고민 중인 선택지:
반드시 지킬 제약:
```

## 긴 대화 정리

```text
현재 목표, 확정된 결정, 변경 파일, 검증 결과, 남은 위험, 다음 작업을 보존하면서 compact해 줘.
```

## 세션 저장

```text
SAVE
```

`SAVE`는 실제 작업과 검증이 끝난 뒤 단독 메시지로 입력한다.
